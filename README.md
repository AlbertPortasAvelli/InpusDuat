# Inpu's Duat

> Personal lost media rescue platform for Catalan content with REST API, advanced search,
> JWT authentication and cloud deployment on Azure.

## Tech Stack
Java 17 · Spring Boot 3 · PostgreSQL · Elasticsearch · Docker · Azure

## Features
- Full CRUD for movies and TV shows
- Advanced search powered by Elasticsearch
- JWT authentication with role-based access control
- Structured logging with correlation IDs
- OpenAPI 3.0 documentation
- Containerized with Docker Compose

## Quick Start
```bash
git clone https://github.com/tuusuario/inpusduat
cd inpusduat
docker-compose up
# API available at http://localhost:8080
# Swagger UI at http://localhost:8080/swagger-ui.html
```
